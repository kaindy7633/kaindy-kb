AI 视频模型路由策略

用途：在 AI 短剧、AI 漫剧、教程消化、平台研发任务中，快速决定使用哪个模型/工具。
维护位置：ai-video-skill-index/references/model-routing-strategy.md。
关联技能：ai-video-production, comfyui, ltx-video-hardware, jellyfish-video-export, douyin-video-digest。

1. 总原则

AI 视频生产不要押注单一模型。推荐采用 多模型路由 + 失败降级 + 成本分层：

核心判断标准：

  1. 叙事一致性：多镜头真人短剧优先。
  2. 角色一致性：reference set、首尾帧、IPAdapter/InstantID、角色库优先。
  3. 成本：草稿、批量、非核心镜头走低成本模型。
  4. 控制力：Storyboard、首尾帧、导演节点、ComfyUI workflow 优先。
  5. 硬件约束：本地模型必须先看 VRAM。
  6. 可维护性：平台内通过 Provider/Gateway 封装，不在业务逻辑里硬编码模型。

7. 常见错误

  1. 把模型排名当永久事实。 AI 视频模型变化快，涉及最新状态必须重新调研。
  2. 真人短剧只看单镜头质量。 短剧更需要角色/场景/叙事连续性。
  3. 每个镜头重新抽卡。 角色一致性会崩，应先建 reference set。
  4. 本地部署忽略 VRAM。 LTX/视频模型对显存敏感，先查硬件。
  5. 平台逻辑硬编码模型。 应通过 Provider/Gateway 路由，便于替换和降级。
  6. 用文本模型处理视觉帧。 视频教程理解要用视觉模型或 Claude Code vision。

8. 维护建议

  • 每次完成重要模型横评/社区研究后，更新本文件的路由策略。
  • 如果新增 Provider，补充 Jellyfish Provider 路由建议。
  • 如果某模型失效、涨价、API 改版，记录到 ai-video-production/references/ 或对应技能。
