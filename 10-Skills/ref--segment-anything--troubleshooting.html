Reporting Issues

Include:

  • Python version
  • PyTorch version: python -c "import torch; print(torch.__version__)"
  • CUDA version: python -c "import torch; print(torch.version.cuda)"
  • SAM model type (vit_b/l/h)
  • Full error traceback
  • Minimal reproducible code
