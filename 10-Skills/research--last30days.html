/last30days — 社区声音调研引擎

核心理念: Google 聚合编辑，last30days 搜索人。

跨 Reddit/X/YouTube/TikTok/HN/Polymarket/GitHub/Web/B站 等平台并行搜索，按真实用户参与度（赞/踩/评论/押注金额/弹幕）评分，AI 合成结构化简报。

代理配置 (Clash)

引擎通过 ~/.config/last30days/.env 自动加载代理设置。已在 env.py 的 get_config() 中实现——从 .env 读取 HTTPS_PROXY/HTTP_PROXY/NO_PROXY 并写入 os.environ，urllib 自动遵循。

配置文件 ~/.config/last30days/.env:

# Overseas sources → proxy
HTTPS_PROXY=http://127.0.0.1:7890
HTTP_PROXY=http://127.0.0.1:7890
# Domestic sources → direct (skip proxy)
NO_PROXY=api.bilibili.com,bilibili.com,*.bilibili.com,zhihu.com,*.zhihu.com,localhost,127.0.0.1

权限: chmod 600 ~/.config/last30days/.env — 引擎会告警如果文件被其他用户可读。

优先级: process env vars > .env file — 如果 shell 环境已设置 HTTPS_PROXY，则 .env 中的设置不会覆盖。

故障排除

海外源不可用时，先检查代理

常见误区: 看到 Reddit/YouTube 返回 “Network is unreachable” 就认为不可用。

正确做法: 先检查本机是否运行了代理（Clash/V2Ray 等）：

如果代理可用，配置 ~/.config/last30days/.env：

HTTPS_PROXY=http://127.0.0.1:7890
NO_PROXY=api.bilibili.com,localhost,127.0.0.1

引擎会从 .env 自动加载代理配置并注入 os.environ（urllib 原生支持）。
