常见故障排查

Celery 任务持续 401（“Authentication Fails”）

根因：Jellyfish 从 providers 表的 api_key 列读取 API key，不是从 .env 的 OPENAI_API_KEY 读取。如果你换了 API key 但只更新了 .env，Celery worker 仍然用 DB 里的旧 key，导致 401。

验证：更新后不需要重启 uvicorn，但重启 Celery worker 保稳。

ComfyUI 在 WSL 上安装需要 python3-venv

分镜帧 Prompt 生成 400

frame_type 取值必须是 first / last / key，不能是 first_frame 等变体。

元素提取 422 需要 script_division

/script-processing/extract-async 的 script_division 是必填字段（object），不能留空。需先完成分镜拆解再传入结果。

技术栈细节

  • ORM: SQLAlchemy 2.0 async（aiosqlite 驱动）
  • 任务队列: Celery + Redis
  • LLM: LangChain（支持 OpenAI/火山引擎/自定义 provider）
  • 存储: S3 兼容（默认代码回退到本地文件系统）
  • 前端: React + Vite + TypeScript + Tailwind（本环境未启动，非必须）
