Daily Multi-Platform AI Video Scan

每天早上8:00 cron 自动扫描 AI 视频前沿动态（7 平台）→ 结构化日报。 覆盖: GitHub / B站 / Reddit / HuggingFace / ArXiv / 抖音 / 小红书 / X/Twitter。

GitHub Search Patterns

关键体会： GitHub search 24h 窗口经常空结果；保守用 3-7 天 range。视频领域新仓库出现在 stars:>50 搜索中的频率比 created:>${yesterday} 高得多。

B站 Search Patterns

推荐关键词组合：

  • AI视频制作
  • AI短剧
  • Seedance
  • ComfyUI教程
  • AI漫剧

提取结果： 返回 JSON 的 data.result[] 包含多个 section（video/user/tv 等）。视频数据在 author key 所在的 section，items 在 data[] 内。字段：bvid/title(含 <em> 标签需replace)/play/duration/pubdate(unix ts)/author。

ArXiv Search Patterns

使用 xml.etree.ElementTree 解析。常用 namespace: {'atom':'http://www.w3.org/2005/Atom', 'arxiv':'http://arxiv.org/schemas/atom'}。entry 字段：title/published(date)/id(URL)/summary/author[]。

Known Pitfalls

  1. GitHub 24h 空结果 — 宽限到 3-7 天，过滤推送时间而不是创建时间
  2. curl | python3 管道被 tirith 拦截 — 先 curl -o /tmp/file.json 再 python3 file.json
  3. DuckDuckGo lite 返回 challenge page — 不适用于自动化搜索
  4. Reddit JSON API 从 WSL 不可达 — 跳过，不需要尝试变通
  5. HuggingFace papers max date — huggingface.co/api/daily_papers?date= 最大接受 today-3
  6. ArXiv 非 HTTPS 被拦截 — 务必用 https://export.arxiv.org
  7. B站 yt-dlp 不加 UA+Referer head 返回 412 — 与 ai-video-skill-index pitfall #7 同
