Fenjing Gushiban → 视频导出 完整管线 (2026-06-15 实战)

末日孤光第1集「最后的信号」— 端到端验证通过

流程总览

剧本(Jellyfish DB) → 角色生成(3角色) → 场景定场(5场景)
  → fenjing-gushiban导演台故事板(5组17面板)
  → 面板关键帧(17张写实1792×1024)
  → shot_details DB回灌(12镜头,景别/运镜/时长/key_frame_prompt)
  → ComfyUI output命名映射(shot_{prefix}_kf.png)
  → FFmpeg Ken Burns 视频导出
  → 成品 MP4 (1920×1080)

Step 1: 角色生成 (GPT-Image-2)

3个角色，使用已有角色参考图描述，1792×1024 16:9。

Step 2: 场景定场图 (GPT-Image-2)

5个场景 each one establishing shot。并行生成会导致全部 524 → 改为串行 + 3次重试 + proxy。

Step 3: fenjing-gushiban 故事板

5组17面板。GPT-Image-2 生成手绘铅笔风格故事板，含中文导演信息栏和颜色标注图例。 超长 prompt（>800词）首试常 524，重试 2-3 次通过。

Step 4: 面板关键帧 (GPT-Image-2)

17张写实风格 1792×1024。分5批，每批内并行线程、批间串行。全部通过 0 失败。

Step 5: DB回灌 (SQLite 直写)

17面板 → 12 shot 映射 + shot_details 全字段填充：

shot_details 更新字段:
  camera_shot, angle, movement, duration, 
  key_frame_prompt (英文), description (中文),
  mood_tags (JSON数组), atmosphere (中文), action_beats (JSON)

Shot 状态: pending → ready。预估总时长: 57 秒（按 fenjing-gushiban 真实台词语速估算）。

Step 6: ComfyUI 图片映射

compositor 查找优先级: shot_frame_images DB 表 → ComfyUI output/ 目录扫描。

命名约定：shot_{shot_id[:8]}_kf.png（匹配 _find_shot_image_in_comfyui_output 的 shot_ 前缀模式）。

Step 7: 视频导出

成品位置: app/storage/exports/chapter_<id>/chapter_<id>.mp4

已知问题

  • image_duration 参数不生效: 12镜头 4.5s/镜 期望 54s → 实际 9s 输出。compositor 内部重算了 segment 时长。
  • Ken Burns 方案被弃用: 用户要求切换到 Seedance 2.0 AI 视频生成（非 FFmpeg zoompan）。

关键指标

  • 总操作时间: ~1小时（含 17 次 GPT-Image-2 API 调用 + 5 次故事板生成）
  • API 调用成功率: 100%（含重试后）
  • 内容安全拦截: 1次（杂兵初始prompt → 降敏通过）
  • HTTP 524 超时: ~6次，全部通过重试恢复
