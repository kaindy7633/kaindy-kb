AI Engineering from Scratch

GitHub: rohitg00/ai-engineering-from-scratch | ⭐ 29,044 | 🍴 4,747 | MIT

一句话定位

AI 工程从零到精通的完整自学课程 — 503 课、20 阶段、~320 小时。Python/TypeScript/Rust/Julia 四语言。每个算法从原始数学推导写起，每课产出可复用工具（prompt/skill/agent/MCP server）。

核心理念：“Build It / Use It”

MOTTO → PROBLEM → CONCEPT → BUILD IT → USE IT → SHIP IT
 (一句话) (痛点)  (图解直觉) (裸数学实现) (框架版) (产出工具)

每课先手写算法裸代码，再用 PyTorch/sklearn 跑同样的东西。你知道框架在做什么，因为你写过一个更小的版本。

对我们最有价值的阶段

Phase为什么重要
Phase 14 (Agent Engineering)与你使用 Hermes 和 Claude Code 直接相关。Agent 循环、记忆系统、Skill 库、工作台——正是 Hermes 的核心机制。42 课，包含 Claude Agent SDK、OpenAI Agents SDK、LangGraph、CrewAI 等。
Phase 11 (LLM Engineering)Prompt 工程、RAG、Function Calling、MCP、缓存/成本控制——日常使用 LLM 的核心技能。
Phase 13 (Tools & Protocols)MCP 深度教程（10 课）、A2A 协议、OpenTelemetry——Agent 基础设施。
Phase 10 (LLMs from Scratch)理解你正在用的 DeepSeek-V3 的内部结构。
Phase 3 (Deep Learning Core)反向传播、优化器——理解模型训练的基础。
