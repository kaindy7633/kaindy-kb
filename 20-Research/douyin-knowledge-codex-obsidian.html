Codex + Obsidian 搭建自生长 AI 知识库

来源: 抖音 @Xuan酱 | 时长 13:22 | 8 章节 标签: AI新星计划 知识库 codex obsidian

一、核心理念：自生长知识库

不是”收藏夹”，而是 由 AI 持续维护的自生长系统。

原始资料(A) → AI消化复盘 → 概念化笔记(B) → 方法论/模板(C) → 输出(D) → 回流

ABCD 文件夹体系

文件夹作用内容示例
A 原始资料未处理的输入网页、论文、截图、视频、飞书文档
B 概念笔记AI 消化后的结构化内容概念卡片、知识图谱
C Skill 库可复用的方法论模板选题判断、写作风格、配图规则
D 输出最终产出（也回流到 A）文档、PPT、视频、周报

二、环境搭建

软件组合

软件角色
Obsidian本地 Markdown 笔记工具，插件生态强大
CodexAI Agent，直接读写本地 MD 文件

打通步骤

  1. Obsidian 设置：设置 → 第三方插件 → 关闭安全模式 → 插件市场搜索 Codex
  2. 配置 Codex CLI 路径：不知道怎么找？直接问 Codex
  3. 关键步骤：Codex 里打开”项目工作”按钮 → 关联 Obsidian 仓库文件夹

三、信息收集自动化（三步）

Step 1：部署资讯聚合工具

把 GitHub 项目（资讯收集工具）丢给 Codex，它会：

  • 从 Twitter、GitHub、Reddit、RSS 抓取内容
  • 自动去重 + 打分
  • 生成结构化日报

Step 2：配置 API Key

AI 会提示需要哪些密钥：DeepSeek、GitHub、各平台 API Key。问 AI “密钥去哪申请” → 生成后发给 AI → 自动配置好。

Step 3：定义身份和需求

我是 AI 自媒体博主，请每天帮我收集 AI 行业热点，把日报推送到指定文件夹。

其他导入方式

来源工具/插件
小红书Obsidian 小红书导入插件（粘贴链接即可）
网页Clip 插件（选中段落 → 剪切收藏，支持视频提取字幕）
飞书文档安装飞书 CLI → Codex 自动导入
Notion / Apple NotesImporter 插件

四、知识迭代系统

把 Karpathy 的思路丢给 Codex → 自动搭建多层级知识库结构，涵盖：

  • 信息输入层
  • AI 消化层
  • 信息输出层

会自动检查：重复内容、过时内容、值得沉淀成模板/方法论的内容。

自动化定期任务（Codex Cron）

案例：每天下午 5 点 → 自动整理当日收集内容 → 生成周间文件 → 存入 Obsidian

可设定期任务清单：

  • 每周复盘总结
  • 月度汇总
  • 选题更新
  • 费书/飞书消息整理 → 自动生成周报
  • HTML 可视化复盘看板

五、Skill 体系（最核心）

任何重复 3 次以上的工作方法，都可以沉淀成 Skill

Skill 示例

Skill 名称作用输入 → 输出
选题价值判断判断新信息的选题价值新信息 → 选题报告（亮点+机会+风险）
文风克隆模仿你的表达习惯写作大纲 → 带个人风格的初稿
去 AI 味让 AI 输出更像真人AI 初稿 → 自然口吻版本
配图自动化自动判断 → 生图 → 插入长文 → 有配图的完整文章
PPT 生成调用 Presentations 插件文档 → PPT
视频摘要调用 Hyperframed 插件文章 → 视频

案例：文风 Skill 效果

“直接总结了我的表达节奏、口语程度、比喻习惯，还提炼了我习惯用的叙事结构，简直比我自己还熟悉自己。“

六、输出能力

输出形式工具
长文/公众号Skill 组合（文风 + 去 AI 味 + 配图）
PPTCodex Presentations 插件，一句话生成
视频摘要Hyperframed 插件，文章 → 视频
周报/复盘自动化 cron 任务生成

七、作者总结

“不用一开始就搭得很完美，先进一个小知识库试试。只要它能帮你省下一次从零开始的时间，就值得继续。”

“当你把资料和方法论都沉淀在 Obsidian 里，AI 就能读到过去的积累，你能直接把产出放回系统。“

八、对 Hermes 用户的启示

视频中 Codex 做的很多事，Hermes 也能做——甚至有些天然优势：

Codex 功能Hermes 等效方案
自动抓取资讯 → 日报cronjob + web_search + RAG
Obsidian 读写Hermes 直接读写本地 MD 文件
Skill 体系Hermes skill_manage 天然支持
定时复盘任务cronjob action=‘create’
飞书文档导入feishu_doc_read 已就绪
网页剪藏web_extract / browser 工具
输出 PPT需 python-pptx（或直接用 Codex 互补）
