一、教程定位

这是AI短剧创作者分享的**“角色资产图”与”场景资产图”制作体系。核心目的：在AI工具链（Midjourney/ComfyUI/Seedance等）中实现角色跨镜头视觉一致性和场景多角度连贯性**。

二、角色资产图体系（6张幻灯片）

方法论框架

每张角色资产图包含以下标准化模块：

┌─────────────────────────────────────────────────┐
│  角色名 + 定位 │ 核心气质 (Core Mood)          │
│  视觉标志 (Visual Signature)                     │
├─────────────────────────────────────────────────┤
│  [多角度转面] FRONT / SIDE / BACK / LEANING      │
│  [动态姿势]   SITTING / CROUCHING / LOW ANGLE   │
│  [表情研究]   6-7格情绪谱系                       │
│  [剪影研究]   黑色剪影 → 验证造型辨识度           │
│  [细节特写]   面部/发型/服装/配饰/道具           │
│  [武器/道具]  独立多角度拆解（可选）             │
│  [比例数据]   身高/体型/多角色对比（BOSS级）     │
└─────────────────────────────────────────────────┘

角色 1：MOLLY — 超能力使用者

  • 气质: Calm, Cool, Controlled, Mysterious
  • 视觉标志: 黑色短发、黄色夹克、液态金属球（超能力特效）
  • 特效资产: 底部一排液态金属球形态变化图（静止→飞溅→串联）—— 这在AI短剧中至关重要，保证特效跨镜头统一
  • 教学重点: 基础多角度转面 + 特效资产管理

角色 2：LEAH — 剑士

  • 气质: Confident, Fierce, Playful, Alert
  • 视觉标志: 金色马尾、粉色轰炸机夹克、武士刀、红色棒棒糖
  • 设计逻辑: 「反差萌」— 少女感外表 vs 危险武器
  • 额外模块: Katana Study（武器独立研究） — 整刀 + 刀柄放大 + 刀鞘樱花雕刻
  • 教学重点: 道具与角色协同建档

角色 3：KING 王 — 队长/拳手

  • 气质: Powerful, Confident, Street Fighter
  • 视觉标志: 红色夹克、金属指虎、骷髅耳环
  • 角色数据卡: 身高185cm、倒三角体型、亚洲人、Captain & Boxer
  • 额外模块: 武器拆解（metal knuckles多角度）+ 身高体型数据
  • 教学重点: 多角色比例参照（同框镜头中与MOLLY/LEAH的身高差一致性）

角色 4：炮弹射手 (Cannonball Shooter)

  • 气质: Rebellious, Confident, Agile, Street Smart
  • 视觉标志: 银色高马尾、轮滑鞋、金色胶囊弹药、运动夹克
  • 模块: 7种角度(含SITTING/CROUCHING/LOW ANGLE) + 弹药研究 + 6项细节(面部/徽章/戒指/斜挎包/轮滑鞋/机械结构)
  • 教学重点: 人类角色的完整资产图模板

角色 5：小兵生物 (Minion Creature)

  • 定位: BOSS/MINION层级中的低级敌人
  • 气质: Feral — Aggressive — Predatory
  • 视觉标志: 毒性绿色血液、多重獠牙、骨刺
  • 世界观: “废墟中诞生的病变杂兵，被饥饿和本能驱使，成群狩猎，只服从最强者”
  • 模块: 三视角肖像 + 4级表情（平静→攻击→警觉→痛苦）+ 解剖细节
  • 教学重点: 非人形怪物的资产图差异化思路——重在头部结构+表情变化范围

角色 6：怪兽BOSS (Boss Creature)

  • 气质: BRUTAL + INTELLIGENT — UNSTOPPABLE
  • 视觉标志: 装甲泰坦、混凝土武器、毒性血液
  • 身高: ~5米
  • 最复杂资产图，包含：
    • 身高对比图（~5M vs 人类）
    • 7种表情（算计→咆哮→暴怒→冷静→威胁→受伤等）
    • 5种姿态（蹲伏/攻击/挥击/俯视/仰视）
    • 6项解剖细节（头骨/手爪/脚爪/装甲板/皮肤/绿血）
    • 武器独立研究：混凝土柱 5项拆解（全貌/钢筋暴露/断裂/握持/冲击损伤）
  • 教学重点: BOSS级角色的完整工业化模板——道具独立拆解是封神之笔

场景资产图核心方法论

  1. 统一编号体系：每个场景用编号标注机位/POI，形成可复用资产库
  2. 分层覆盖：宏观（鸟瞰建立世界观）→ 中景（平视代入人物）→ 微观（细节增强真实感）
  3. Prompt 生产模板：每个格子对应一个AI生图Prompt，创作者按编号调用
  4. 连贯性保障：同一场景不同角度保持色调/材质/光线统一

五、对AI短剧平台开发的启示

1. 角色系统需要”Visual Bible”模块

当前Jellyfish平台的分镜系统可以扩展为：

  • 角色库 → 每个角色绑定一套资产图（多角度 + 表情 + 武器 + 数据）
  • 资产图作为ComfyUI/Seedance的reference image输入

2. 场景系统需要”机位地图”

  • 每个场景建立编号化机位体系（外景7机位 + 内景11机位）
  • AI生图时按机位编号调用对应prompt模板
  • 场景与角色联动：人物在场景中的比例、光影关系

3. 道具系统独立管理

  • BOSS的混凝土柱、LEAH的武士刀 → 都有独立多角度拆解
  • 道具资产与角色资产分离但联动
  • 确保AI生成特写镜头时道具形态不扭曲

4. 工业化模板化

这套体系的本质是把AI生图的不确定性通过标准化参考锚定：

  • 角色：Core Mood + Visual Signature → prompt种子词
  • 场景：Camera Key编号 → 镜头语言规范
  • 武器：独立Study → 避免AI”遗忘”细节

5. 可以直接借鉴的产出物

  • 角色资产图模板（6种层级：人类基础/进阶/BOSS + 怪物小兵/BOSS）
  • 场景资产图模板（外景+内景，编号化机位体系）
  • 这套方法论对Seedance 2.0多镜头叙事一致性功能有直接增强价值
