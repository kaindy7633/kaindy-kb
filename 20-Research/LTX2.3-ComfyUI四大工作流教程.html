LTX 2.3 保姆级工作流教程 — 四大核心管线

来源: 抖音 @啦啦啦的小黄瓜 | 时长 18:19 | 2026-03-17 标签: LTX2.3 ComfyUI工作流 AI视频 文生视频 图生视频 数字人 数据: 348赞 · 19评 · 330分享 · 65收藏 解析: Hermes Agent 自动消化 (Chapter文本 + 页面元数据)

一、视频概要

本教程分享了 LTX 2.3 在 ComfyUI 中的四个核心工作流，覆盖从基础到高级的视频生成场景。作者强调这4个工作流可以通过参数调整互相转换——一个万能工作流骨架，通过修改参数适配不同需求。

二、四大工作流

1. 文生视频 (Text-to-Video)

最基础的生成模式。纯文本提示词驱动，LTX 2.3 从零生成视频。

关键参数（来自教程）:

  • 模型选择: LTX 2.3 系列 checkpoint
  • 提示词结构: 详细描述场景+动作+风格
  • 采样参数: 步数、CFG、噪声调度
  • 输出规格: 分辨率/帧数/时长配置

2. 图生视频 (Image-to-Video)

给定一张参考图，LTX 2.3 基于该图生成连贯视频。适合需要特定视觉起点的场景。

3. 首尾帧 + 语音 (First/Last Frame + Audio)

最灵活的混合工作流，通过参数切换可降级为多种子模式：

模式参数调整效果
数字人对口型首帧图 + 音频（不上传尾帧）图+音频→说话视频
首尾帧视频首帧+尾帧（不上传音频）指定起止画面的过渡视频
首尾帧+语音全参数完成版：起止画面+配音同步

作者强调：这个工作流是”万能骨架”，参数调整即可切换模式。

4. 多图参考 (Multi-Image Reference)

上传多张参考图驱动视频生成：

  • 作者示例: 上传了6张图
  • 可通过工作流调整到 3~20+张图片
  • 适用于复杂场景/多角色/多视角的视频

三、核心参数详解（来自教程 Whisper 转写）

FPS/帧率

帧率效果建议
60最佳动态表现，口型变化流畅✅ 作者实测推荐
48出现画面重映（ghosting）❌ 不推荐
28官方默认帧率⚠️ 基础可用
24也可用⚠️ 最低可接受

关键洞察：数字人对口型场景需要高帧率，因为嘴巴动作变化多。作者原话：“帧率越高越好，60已经很不错了”。

LPS (每张帧对应图片数)

  • 作者设置: 60
  • 15秒视频 @60fps → ~900总帧
  • LPS值决定每张关键帧的间隔密度

提示词黄金法则

规则说明
对话之外用英文LTX 模型国外训练，英文识别能力更强
中文对话写中文人说的话必须用中文
可加语言前缀”用标准的中国普通话正在说: …”
字数上限≤500字，太多模型理解不了

四、通用参数体系

教程中系统讲解了各工作流共通的参数：

参数类别关键项说明
模型加载Checkpoint / LoRALTX 2.3 基础模型 + 可选 LoRA
提示词书写正向/负向提示词结构化的场景+动作+风格描述
采样参数Steps / CFG / Sampler决定生成质量与速度的平衡
视频输出分辨率/帧数LTX 约束: 宽高整除32, 帧数 8n+1
视频合并多段拼接长视频分多段生成后拼接
